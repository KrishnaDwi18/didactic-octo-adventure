# Academic Writing AI Skill

An AI-powered academic writing skill designed to improve academic vocabulary, sentence structure, clarity, and coherence in Social Sciences, International Relations, and Political Science.

## Overview

This project provides structured instructions and a curated academic phrase library to help AI assistants produce clear, precise, and context-aware academic writing.

The skill prioritizes preserving the author's original meaning while improving scholarly expression.

## Key Features

- **Academic Vocabulary:** Replaces informal expressions with appropriate scholarly terminology.
- **Sentence Structure:** Improves clarity, coherence, and logical connections.
- **Discipline-Specific Writing:** Supports International Relations, Political Science, and related Social Sciences.
- **Critical Analysis:** Encourages balanced arguments and appropriate qualification.
- **Research Integrity:** Discourages fabricated evidence, references, and unsupported claims.

## How to Use

1. Download `SKILL.md` and `references/academic-phrases.md`.
2. Upload both files to an AI assistant that supports file attachments.
3. Ask the assistant to follow the instructions in `SKILL.md` and use the phrase library.
4. Provide a paragraph for academic rewriting or critical analysis.
5. Review the output for accuracy and preservation of meaning.

## Example Prompt

"Rewrite the following paragraph in a scholarly style suitable for International Relations research. Improve academic vocabulary and sentence structure without introducing unsupported claims or fabricated references."
